# 性能实测

测量环境：M 系列 Mac（Apple Silicon），macOS 27.0.1，Xcode 27.1 Release 构建。

## 检测吞吐（离线回放，smartshot-replay CLI）

对完整真实课程录像灰度流的逐帧回放（含两级检测 + 策略状态机全部逻辑）：

| 流 | 帧数 | 耗时 | 吞吐 |
|---|---|---|---|
| 20.mov F_buffer | 5862 | 0.41 s | ~14,270 fps |
| 13.mov F_buffer | 8408 | 0.60 s | ~14,080 fps |
| 20.mov C_region | 5862 | 0.44 s | ~13,260 fps |

实际工作点是 1fps 输入，检测预算利用率 < 0.01%——
两级结构（第一级 XOR 预筛挡掉绝大多数帧）在真实数据上富余极大。

## 内存

- 分析帧：320×180 = 57.6 KB/帧。
- 策略 pending 缓冲：最多 persistFrames 帧 ≈ 115 KB（persist=2）。
- FrameBuffer 环形缓冲：容量与字节双预算（默认配置 ≈ 数 MB 上限，可在设置中调整）。
- 与录像时长无关：全部缓冲为常数上限，不随课程长度增长。
