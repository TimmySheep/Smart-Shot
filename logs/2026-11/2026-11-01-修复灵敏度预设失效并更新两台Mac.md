# 2026-11-01｜修复灵敏度预设失效并更新两台 Mac

## 现象

设置里「灵敏度」选「保守 / 标准 / 敏感」，检测参数不变，行为完全一致。

## 根因

- `AppSettings.sensitivity` 的 `didSet` 只写 UserDefaults，不更新高级字段。
- `makeParameters()` 先用 `switch sensitivity` 写入预设值，紧接着又用
  `prefilterBits / regionPeak / pagePixels`（默认 8000/20/3000）无条件覆盖。
- 两者叠加后，预设永远被标准值覆盖，`sensitivity` 成为纯展示状态。

## 修改

- `AppSettings.swift`
  - 新增 `sensitivityPreset(_:)` 作为唯一预设表（保守 15000/60/3000、标准 8000/20/3000、敏感 5000/12/1500）。
  - `sensitivity.didSet` 追加 `applySensitivityPreset()`，把预设同步写进三个高级字段。
  - `makeParameters()` 改用 `sensitivityPreset`，保留高级字段作为后续手工微调。
- `README.md`：灵敏度说明改为指向「设置 → 灵敏度」选敏感（该入口现已生效）。
- `project.yml`：`MARKETING_VERSION` → 0.2.2，`CURRENT_PROJECT_VERSION` → 4。

## 验证与发布

- Debug 编译通过；Release 0.2.2 (build 4) 在 Pro 的 GUI 会话内以
  `Apple Development: timmysh34@icloud.com` 签名，`codesign --verify --deep --strict` 通过。
- 二进制 SHA-256 `107504628f633df0af0c258294294501c2596c3bfa6499510da4fad9b19c4083`，
  两台 Mac 安装后回读一致。
